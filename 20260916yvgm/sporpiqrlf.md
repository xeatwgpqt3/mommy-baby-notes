# 【抗“疫”群英谱】战“疫”一线的“拼命三郎”——记解放军总医院海南医院热带医学科主任李慧灵

> 更新时间：2026-09-16 (UTC+8)

她，解放军总医院海南医院发热门诊负责人。  

她，三亚市新型冠状病毒感染救治专家组副组长。

她，三亚市新型冠状病毒主动防疫采样发起人。

她，31天没有踏进家门，一直奋战在疫情防控一线。

她，今年44岁，头发却已半白，还是两个孩子的母亲。

她，解放军总医院海南医院热带医学科主任李慧灵。

▲李慧灵在发热门前
“所有人员5点到会议室开会！”1月20日下午，一个急促而又坚定的声音穿透海南医院热带医学科病房，科室医护人员都知道这是李慧灵主任的声音，但这个声音非比寻常，所有人揣着不安的心情来到了会议室。李主任表情严肃地向大家宣布：“热带医学科全体人员取消年休假，明天支援发热门诊，新型冠状病毒疫情形势严峻，大家要做好准备，加强防护，我不允许你们当中的任何一个感染，我陪着大家一起战斗”。话音刚落，所有人员分头各自准备下一步的防疫工作。海南医院新冠肺炎疫情防控阻击战由此吹响战斗的号声。

▲李慧灵（左三）向总医院领导介绍发热门诊工作情况
牢记初心使命，坚决无条件服从医院党委命令安排，冲锋陷阵在一线。李慧灵作为抗击疫情发热门诊临时党支部副书记，也是医疗工作主心骨。这段时间，她既要在一线救治新冠肺炎患者，又要协调防治工作，很少休息，身心疲惫，但从不退缩，作为一名40多岁的女同志，头发却已半白，被同事们称为“拼命三郎”。面对新冠肺炎高传播能力的这一全新未知的疾病，她深知，保护好每一个一线工作人员是临时党支部的首要任务，在临时党支部的带领下，她不但无惧艰难，主动请战，更积极为大家解除顾虑，严把防控关，做到了医护人员“零感染”。

“应对暴发式疫情最关键的就是反应要快！”这是李慧灵挂在嘴边上的话，在快速传播的疫情面前，只有更快，才能遏制疫情发展。基于这一理念，她力争主动防疫，在医院设备、物资紧缺的情况下，她主动请缨，想方设法，仅用12小时，就将全部核心设备和物资协调到位，并完成检修检验；24小时后，发热门诊正式开诊运行，核酸检测实验室全面开始工作。

面对疫情反应快，就是要做到“早发现、早隔离、早治疗”。李慧灵带领带团队在春节前的重点人群预筛查中发现，一名湖北籍女性游客，没有明显的感染症状，筛查结果却为阳性，联系到她时，正准备登机飞往云南，十万火急，李慧灵立刻上报三亚市疫情防控办公室，采取紧急措施将该游客隔离，防止了病毒的传播扩散。无独有偶，节后一批武汉籍游客准备包机返回武汉，其中一名女性乘客，无明显感染症状，在接受重点人群筛查后结果呈阳性，登机前被紧急隔离，这又一次消除了病毒跨区输出传播的可能。

在李慧灵主任的带领下，抢速度敢斗争，通过全体发热门诊工作人员的共同努力，提前了疾病确诊中重要的一环——核酸检测，更快更早地检测患者病毒核酸，建设了海南省通量最高的新冠病毒核酸实验室，该实验室早期快速检测到接近80%的三亚阳性感染者。截至2月16日，发热门诊共接诊患者2728名，其中，有湖北旅居史的627名，筛查上报41名核酸检测阳性患者，为海南医院赢得了荣誉。三亚市是海南省内最早关口前移进行核酸检测的城市，受到海南省委主要领导的赞誉。

“你们每一个人，面对每一名采样对象都要把他想象成高危传染源，只有这样大家才能严格按照感染疾病规范去采集样本，最大程度保护大家，避免被感染。”在疫情采样员的培训现场，李慧灵主任严肃地说。

从提出“早期快速找出传染源”的建议，到三亚市政府快速接纳并迅速形成规模，再到第一批疫情采样员完成培训前出采集样本，只用了短短1天时间。李慧灵承担了三亚市主动防疫采样负责人的工作，协调了全市各级公务员、公安民警、医生护士、公共卫生管理人员等数千人，工作任务庞杂繁重但卓有成效。

特别是三亚市水蛟村的疫情采样筛查工作，一个只有几百人的小村子聚集了大量的武汉候鸟人群，经过迅速的采样筛查，确诊了10余名阳性新冠肺炎患者和携带者，情况报告给三亚市后，紧急对该村进行了管控，杜绝了病毒在三亚市蔓延。三亚市民纷纷点赞李慧灵团队的“神速”筛查，避免了水蛟村变成三亚市的“武汉”。

▲李慧灵（左一）向三亚市领导汇报疫情采样工作情况

海南医院筛检出的阳性感染者中，有60%的无症状或轻症状的无就医需求者，这些人是行走在人群中隐藏的传染源。这项工作快速及时找到并控制传染源，从源头上遏制疫情，也避免了部分感染者在长达一周甚至更长的无症状时间内产生暴发性传播，做到了精准防疫。更有意义的是，这项工作也是全国第一份全面对某一独立地区武汉旅居者大样本筛查，取得的数据为全国疫情防控提供了参考，受到了钟南山院士的充分肯定和褒奖。

一边是对疫情的铁肩道义，另一边则是对家人的无声歉意。投入到疫情防控工作以来，李慧灵已经31天没有进过家门。除夕，她一直在发热门诊前指挥吊装核酸实验室检测点，这是她人生中第一个没有祝福、没有年夜饭的除夕。

“除夕，我和科里的几个同事裹着毛毯在发热门诊前通宵安排核酸实验室吊装的工作，家里人的电话那时根本打不进来，我的手机一直在通话协调各种事情。”李慧灵回忆除夕当天的情况，一度有些哽咽,“也是几天之后，稍微不那么忙了，才给家里打了电话，连接了视频。”

▲李慧灵和专家讨论疫情救治工作

本是一介女流，但却戎装加身。李慧灵是海南医院2014年特招入伍的一名高级专家，自从穿上军装的那天起她就严格按照一名军人的要求来约束自己、锤炼自己。在医院的道路上，总是能看见她披着白大衣行如疾风的样子，好像有很多事儿等着她去完成。也是她“疾风”一样的性格，才让她在疫情面前处事果断，敢于担当。
李慧灵的战“疫”形象是海南医院整体应对新冠肺炎疫情防控工作的一个缩影，像她这样默默战斗在疫情一线的人还有很多。在这场疫情阻击战中，海南医院人积极迎战，不但主动冲到疫情一线，而且与三亚市政府紧密联系，积极为三亚市疫情防控工作建言献策，充分利用医院的技术优势，不断完善医疗救治方案，为三亚打赢疫情防控阻击战提供了坚强信心。
