# 孕期必备的4种营养素，这样补才对！

> 更新时间：2026-09-16 (UTC+8)

**合理补充微量营养素**

**助力整个妊娠期**

妊娠期是生命的起始阶段，孕前及孕期合理的营养就像阳光雨露，对孕产妇自身健康、胎儿以及婴幼儿健康成长和发育至关重要。

我国不少孕妇的妊娠期营养状况面临能量摄入相对过剩，但**微量营养素**却缺乏的双重挑战。**那孕前和孕期我们如何进行微量元素的补充呢？**

**妇幼健康科普**

**关于叶酸补充**

建议至少从妊娠前 3 个月开始到妊娠满 3 个月补充叶酸。研究表明，**妊娠中、晚期孕妇继续补充叶酸或含叶酸的复合维生素的母儿获益显著。**推荐孕妇在妊娠中、晚期持续补充叶酸或含叶酸的复合维生素。在不考虑膳食叶酸的基础上，**从营养补充剂中额外获取的叶酸总量（不包含膳食叶酸）不建议超过1 mg/d，**并避免联用有相同成分的补充剂。

**关于钙剂补充**

孕妇缺钙不仅影响胎儿的骨骼发育，还会引起孕妇血钙降低，发生近期腓肠肌痉挛和远期骨质疏松等。**指南建议从妊娠中期开始每天至少补充钙剂600mg直至分娩**；建议孕妇在日常适当户外活动获得充足日照的基础上，选择含维生素D的钙补充剂。

由于孕妇人群的特殊性，缺乏临床相关研究数据，但在其他人群中已证实有机钙（如柠檬酸钙）相比无机钙（如碳酸钙）在提高钙吸收率方面获益较多。

**维生素D缺乏可导致肠道钙吸收下降超过75%**，且研究证实，维生素 D 对于妊娠结局和子代的长期健康具有重要影响。因此，补钙的同时应与维生素D联用，以改善钙吸收。

研究已证实，妊娠期合理补钙对母儿健康有积极影响，可预防子痫前期的发生，有助于孕妇产后骨骼恢复并减少子代龋齿的发生。

**关于铁剂补充**

多个国家的相关指南均建议妊娠早期筛查**Hb和血清铁蛋白（SF）水平**，当SF<20 μg/L应考虑**缺铁性贫血**，SF<30 μg/L即提示铁耗尽的早期，需及时补充治疗。

**关于DHA的补充：**

**建议妊娠期食用富含omega-3脂肪酸的食物（如鱼类等水产品）**，每周 2~3 次；对于日常饮食不能满足的孕妇，可考虑每天额外补充200mg 二十二碳六烯酸（DHA）直至哺乳期结束。

孕妇维持适宜的omega-3脂肪酸水平有益于改善妊娠结局和降低子代罹患过敏性疾病的风险。我国多区域的膳食容易存在omega-3脂肪酸摄入不足，因此，建议孕妇在日常饮食的基础上，额外补充DHA 200mg/d 直至哺乳期结束。

**除了微量营养素的补充，体重的管理也至关重要**，为响应国家“体重管理年”，我们需要知道自己的体重目前处于什么水平。我国定义BMI 24.0~28.0 kg/m²为超重，BMI≥28.0 kg/m²为肥胖。孕前不同体重指数，孕期体重增长是不同的。

**1、妊娠前低体重**［体重指数（BMI）<18.5 kg/m² ］妇女，推荐妊娠期体重增长（GWG）范围11.0~16.0 kg；

**2、妊娠前正常体重**（BMI18.5~24.0kg/m²）妇女，推荐GWG范围 8.0~14.0 kg；

**3、妊娠前超重**（BMI24.0~28.0 kg/m² ）妇女，推荐GWG范围7.0~11.0 kg；

**4、妊娠前肥胖**（BMI≥28.0 kg/m² ）妇女，推荐GWG范围5.0~9.0 kg。
