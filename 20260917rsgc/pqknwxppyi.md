# 九江市妇幼保健院疫情防控告知书

> 更新时间：2026-09-17 (UTC+8)

尊敬的患者/孕产妇及家属：

您好！

近期全国新冠肺炎疫情防控形势复杂严峻，为全力维护来院群众的生命安全和身体健康，根据疫情防控相关法律法规和上级通知要求，有效应对疫情，现将就诊相关事宜告知如下（甘棠院区与八里湖院区同步执行）：

**01 / 来院须知**

1.所有来院人员均需严格落实“四查一戴”要求（四查：查验健康码、查看行程轨迹、查新冠疫苗接种记录、测量体温，一戴：全程佩戴口罩）。无智能手机的群众，请配合工作人员登记相关信息。请勿佩戴布质或带呼气阀的不合格口罩。主动与他人保持1米以上安全距离。

2.黄码、红码人员需配合我院防控措施进行处置，对于不配合执行疫情防控措施者，拒绝进入院区。

3.所有就诊人员均需接受流行病学史问询和预检分诊，请务必如实告知预检分诊处工作人员，不隐瞒、不提供虚假信息。行程码带*（近14天可能到达或途径有中高风险地区的城市）的绿码来院人员应如实提供行动轨迹，签署流行病学调查承诺书，并配合指挥部疫情防控要求落实相关措施。

4.为节约您的宝贵时间，并减少在院滞留时间，推荐您关注“九江市妇幼保健院”微信公众号预约挂号、缴费、查询检验结果。复诊患者可通过互联网医院进行诊疗完成问诊及购药。

5.为减少医院人群聚集，门诊实行非必要不陪护，儿童、危重/临产孕产妇、70岁以上行动不便的老年患者就诊时可有1名家属陪护，严格执行“一医一患一诊室”实名制就诊。住院部严格执行“一人一陪护”政策，建议每名儿童患者/孕产妇仅限一名家属陪护，非必要不陪护、不探视，谢绝所有中高风险区域旅居史家属陪同来院。

6.医院各楼层均放置有黄色医疗垃圾桶，请将废弃口罩、帽子等投入其中。在院区内请减少触摸公共物品的次数，注意手卫生。

**02 / 发热门诊就诊须知**

我院两院区发热门诊均实行24小时值班制。如有发热或疫情中高风险地区/境外返赣人员，请主动按标识指引到发热门诊就诊，发热门诊就诊者必须进行核酸和血常规检查，必要时实行胸部CT等检查。

所有首次前来就诊的发热患儿（本次起病有发热症状），需门诊留观等待核酸结果，结果阴性方可离院。核酸检测结果未出如需住院请配合在儿童缓冲救治病区（八里湖院区）等待核酸检测结果。

**03 / 门诊就诊须知**

1.为避免窗口人员聚集，非发热患者/孕产妇可关注医院公众号预约挂号或在医院自助机端挂号。（发热首次就诊患者请到发热门诊就诊，接受现场挂号。）

2.患者/孕产妇就诊前需在各楼层分诊台进行测温、流行病学调查，请如实告知医务人员旅居史，正确填写并完善监护人身份证、家庭住址（具体到门牌号）、联系电话等基本信息，主动出示健康码、行程码，不隐瞒、不提供虚假信息。

3.行程码带*（近14天可能到达或途径有中高风险地区的城市）的绿码来院人员应如实提供行动轨迹，确未到达中高风险地区的需签署承诺书方可就诊。

4.如有发热、干咳、乏力或自疫情中高风险地区/境外返赣人员，将由工作人员引导至发热门诊就诊。

5.在相关检查、缴费窗口、自助机、取药等候时，请自觉排队并保持1米以上距离。

6.门诊实行非必要不陪护，儿童、危重/临产孕产妇、70岁以上行动不便的老年患者就诊时可有1名家属陪护，严格执行“一医一患一诊室”，他人结束就诊前不要进入诊室。

**04 / 住院患者及陪护须知**

1.所有住院患者/孕产妇及陪护人员需持48小时内新冠核酸检测阴性结果方可办理住院入病区，其他人员不得进入病区。住院期间住院患者/孕产妇及陪护人员请配合医院按照疫情防控要求进行复查。

2.住院病房实行严格的人员进出管理，禁止探视，住院患者/孕产妇及陪护人员凭腕带或核酸检测阴性结果进入病区，谢绝发热、咳嗽人员进入病区陪护。为保障您及家人的安全，原则上一名家属陪护，固定陪护人员，住院时进行信息登记。

3.陪护人员在陪护期间原则上不允许更换，如有特殊情况需更换陪护人员，应主动告知病区护士长并提供48小时内核酸检测结果和查验体温、健康码、行程轨迹。

4.患者/孕产妇和陪护人员禁止随意离开病房及院区，正确佩戴好口罩、勤洗手、不串病房、不聚集等。遵守医院的管理制度，并主动配合医务人员进行体温筛查及信息登记。如陪护人员出现发热、咳嗽，应立即向医务人员通报，并到医院指定地点就诊。

5.住院患者/孕产妇、陪护人员有以下情况者，应主动如实告知医务人员：

（1）14天以内有境外、中高风险地区旅居史；

（2）14天以来有接触过来自境外、中高风险地区有发热伴有呼吸道症状的人群；

（3）有发热、乏力、咳嗽或其它可疑不适症状；

（4）与近期公布的密切接触者活动轨迹有交集者。

**05/ 核酸检测须知**

1.挂“核酸检测”门诊号后直接到两院区相应的非发热核酸采样区采样（建议关注医院公众号挂号、缴费、查结果）。陪护人员及愿检尽检人员核酸采样可通过自助缴费机或支付宝进行缴费，无需进入诊疗区域，在指定采样点完成采样。

2、非发热核酸采样区标本采集时间为24小时，建议上午8:00-12:00，下午14:00-16:30来院。两院区均24小时提供采样服务。

3.核酸检测结果可关注医院公众号或24小时后扫赣通码查询，纸质版需在医院自助机端打印。如果检测结果需加盖医院公章，您可在工作日时间到医务科办理。

**温馨提示**

疫情防控特殊时期，请您自觉遵守医院相关规定，医院防控措施将根据全国疫情形势变化进行动态调整，给您带来不便，敬请谅解！九江市妇幼保健院全体员工将全力以赴与您携手共击新冠疫情！
